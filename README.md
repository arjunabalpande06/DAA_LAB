# 🧮 Design and Analysis of Algorithms (DAA) – Lab

A collection of algorithm implementations, laboratory experiments, and problem-solving programs developed as part of the Design and Analysis of Algorithms coursework.

## 📌 About the Repository

This repository contains practical implementations of fundamental algorithms used in computer science. It focuses on understanding algorithm design techniques, analyzing computational complexity, and developing efficient solutions to computational problems.

The programs demonstrate different algorithmic approaches, including searching, sorting, divide and conquer, greedy algorithms, dynamic programming, and graph algorithms.

## 🎯 Objectives

- Understand fundamental algorithm design techniques.
- Implement different searching and sorting algorithms.
- Analyze time and space complexity.
- Apply divide and conquer strategies.
- Understand greedy algorithm approaches.
- Solve problems using dynamic programming.
- Implement graph-based algorithms.
- Improve logical thinking and optimization skills.

## 📊 Algorithm Complexity

Some commonly studied algorithms and their time complexities:

| Algorithm | Time Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Bubble Sort | O(n²) |
| Selection Sort | O(n²) |
| Merge Sort | O(n log n) |
| Quick Sort | O(n log n) Average |
| BFS | O(V + E) |
| DFS | O(V + E) |
| Dijkstra's Algorithm | Depends on implementation |

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- GCC / G++ Compiler
- Visual Studio Code or another IDE
- Windows, Linux, or macOS

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/DAA_LAB.git
```

### 2. Navigate to the Project Directory

```bash
cd DAA_LAB
```

### 3. Compile a C Program

```bash
gcc filename.c -o output
```

For C++ programs:

```bash
g++ filename.cpp -o output
```

### 4. Execute the Program

**Linux / macOS:**

```bash
./output
```

**Windows:**

```bash
output.exe
```

Replace the filename with the actual source code file you want to execute.
